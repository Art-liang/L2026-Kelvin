# Kelvin 命理驗證資料庫

斗數小學堂｜小梁製作彙整。

網站入口：`index.html`（靜態單檔 HTML）。

## 搜尋引擎索引設定

網站 HTML 包含 `robots`、`googlebot`、`bingbot` 的 `noindex, nofollow` 等指示，希望搜尋引擎不要建立索引。這不等於私人網站，任何知道網址的人仍可能訪問、轉傳或複製內容。GitHub Pages 一旦啟用，公開網站也可能被第三方服務記錄。

## 注意

網站含個人命理諮詢、人生事件等內容；請在更新前確認公開授權。驗證資料若只儲存在瀏覽器的 `localStorage`，不同裝置不會自動同步。
